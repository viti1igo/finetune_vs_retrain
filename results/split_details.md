# Train/Test Split Details (Dataset B: KlebPhaCol)

## Methodology
- **Strategy**: Hierarchical Strain-Level Partitioning (80% Train, 20% Test)
- **Leakage Prevention**: Host strains assigned exclusively to either Train or Test to evaluate generalization to novel host strains.

## Statistics
- **Total Pairwise Interactions**: 3150
- **Train Split Pairs**: 2520 (24 unique hosts)
- **Test Split Pairs**: 630 (6 unique hosts)
- **Train Class Balance**: Positives = 1469 / 2520 (58.3%)
- **Test Class Balance**: Positives = 359 / 630 (57.0%)
